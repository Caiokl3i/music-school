# Caio Music

Site vitrine desenvolvido em **React** para apresentar aulas de instrumentos musicais, com foco em design limpo, navegação simples e experiência responsiva.

## Sobre o projeto

O **Caio Music** é uma plataforma de apresentação pensada para quem quer conhecer os cursos, ver a galeria de estilos e entrar em contato para agendar aulas. O conteúdo cobre violão, bateria e piano, com níveis do iniciante ao avançado.

### Páginas

- **Início** — apresentação, destaques e informações sobre as aulas
- **Cursos** — catálogo com filtros por instrumento e nível
- **Galeria** — estilos musicais e momentos de aula
- **Contato** — formulário e canais de comunicação

## Tecnologias

- React
- React Router
- Vite
- CSS Modules
